# Pipeline — Clay Bureau visual identity

## Mark
Circular ink disc with a terracotta live bar.
Clear space: one bar-height on all sides. Minimum size 16px.

Files
- pipeline-mark-primary.svg — ink disc, clay live bar (default)
- pipeline-mark-inverse.svg — clay disc, white bar (on photographic / dark)
- pipeline-mark-avatar.svg — circular variant for avatars and favicons
- pipeline-mark-transparent.svg — outline + bar, for light surfaces
