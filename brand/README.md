# Pipeline — visual identity

## Mark
Circular dark purple disc with three ascending white bars (signal / stages).
Clear space: one bar-height on all sides. Minimum size 16px.

Files
- pipeline-mark-primary.svg — purple disc, white bars (default)
- pipeline-mark-inverse.svg — white disc, purple bars (on photographic / dark)
- pipeline-mark-avatar.svg — circular variant for avatars and favicons
- pipeline-mark-transparent.svg — outline + purple bars, for light surfaces

Disc colour sampled from CI: `#2B1A2F`
